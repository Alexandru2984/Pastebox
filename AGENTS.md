# Repository instructions

- Local commits are authorized after each completed fix or stage. Use the repository owner's existing author identity. Do not add AI attribution, contributor credit or coauthor trailers.
- Do not push commits, update remote branches, merge pull requests or otherwise publish repository changes without the user's explicit approval for that action. Authorization to edit, test or commit locally is not authorization to push. Reading GitHub Actions logs/status with `gh` is permitted.
- Build and run destructive/security/browser tests only against disposable databases and separate loopback servers. Do not use customer pastes as test fixtures.
