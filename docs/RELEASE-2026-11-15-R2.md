# PasteBox release 2 — 2026-11-15

Installed on https://pastebox.micutu.com/ at approximately 18:41 UTC. The native binary and every new static file match the tested artifacts. Existing tabs retain access to older hashed assets; reload old tabs before editing so they send revision preconditions.

## Delivered

- Owner-only history with up to 10 previous snapshots, bounded line comparison, restore as a new revision and explicit history clearing.
- Conditional saves/restores/clearing with `If-Match`: stale edits receive 412 and keep their unsaved text. Missing edit preconditions receive 428.
- Restoration keeps current visibility, owner capability, reading password and expiration. History is not available to readers or owners of forks. One-time pastes never keep reusable snapshots.
- Transactional snapshots/edits/tags and persistent deletion cleanup, including expiration and connections with foreign-key enforcement disabled.
- Markdown preview before publishing and while reading, with lazy worker/sanitizer loading, parser time/size/complexity limits, escaped raw HTML and hidden remote images.
- Sandboxed preview without scripts or parent-origin storage access; restrictive embedded CSP and web links with no opener/referrer. Source is preserved on errors/timeouts.
- Aggregate scrypt budget (4/second, burst 8), in addition to per-IP budgets. Busy derivations return 429 with a one-second retry hint; owner-key reads bypass derivation.
- Legacy forks reload the password verifier after authorization upgrades it, preventing propagation of the stale SHA-256 verifier.
- Mobile Markdown controls, proper file-extension badges, bounded notification widths and downloads that preserve an imported filename's existing extension.
- Read-only UI verification (`npm --prefix frontend run smoke:ui`) that blocks writes/third-party requests and never publishes a test paste.

## Verification

- 99 frontend cases, 28 isolated API cases and 18 desktop/mobile browser flows passed: 145 cases total.
- Native C++ build and the full API suite passed; the distribution C++ build/API suite also passed in a CPU/memory-limited Ubuntu 24.04 container. Host libraries were not replaced.
- Password-budget regression checks admitted work against burst/refill over the measured interval. A CPU-limited machine legitimately accepts all offered requests when its throughput is already below the quota.
- Browser flows cover compare/restore/clear, two-tab conflicts, imported-file download names, preview without publishing, hostile markup, blocked parent-storage access, absent image requests and theme changes.
- Public API/static/SEO/embed smoke checks passed through Cloudflare. The live UI check verified an unpublished Markdown draft at 375px and 320px with zero write attempts and zero runtime errors.
- Snapshot integrity and a separate local restore were verified before rollout. Live integrity, the additive revision schema/cleanup trigger and preservation of active pre-release record IDs were checked without reading customer bodies.
- Live binary/static files were byte-compared with the test build. Service remained active with no automatic restarts after deployment.
- Runtime npm audit reports zero advisories. The same two low build-only `deepmerge`/Svelte-plugin findings remain without an available upstream fix.

## Recovery and limits

Restricted snapshot and prior artifacts: `/var/backups/pastebox/release-20261115T184120Z-eILgvn`. Ordinary artifact rollback must keep the live database; follow [operations](OPERATIONS.md). Reverting to a pre-revision build requires restricted writes until the forward fix/client reload because that build cannot enforce revision preconditions.

Snapshots contain earlier title/content/language/tags, not credentials or old access policies. Clear-history removes active rows; older backups/free SQLite pages can retain bytes. The shared database page ceiling includes revision content. Markdown preview supports 128 KiB / 3,000 lines / 5,000 rendered elements, while full source support remains 512 KiB.

Remaining product/operations work: multi-file documents, accounts/cross-device recovery, client-side encryption, reporting/moderation, encrypted off-host backups, monitoring/alerts and independent review. Remote GitHub Actions execution still awaits a push; this release does not push the repository.
