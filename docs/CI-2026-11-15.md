# GitHub Actions failure investigation

The first remote run of the published release failed: [main run 43755163652](https://github.com/Alexandru2984/Pastebox/actions/runs/43755163652). The C++ build, API cases, frontend cases/audits/build and browser installation passed in that run; two mobile browser scenarios failed. Dependency PRs also failed either the API suite or mobile workflows. Passing local runs had not established remote CI reliability.

## Cause and correction

The suites reused one backend process for multiple independent cases. On the faster GitHub runners, unrelated cases exhausted shared process-wide password quotas or the browser IP's write quota. API assertions received `429` instead of `200`/`201`. Browser traces showed “Too many requests” after Save, leaving the edit form open. These were observable test-isolation failures, not evidence that dependency updates broke the application.

- Each API case now starts a separate backend/database, migrates fresh legacy fixtures and tears down its process even after setup/assertion failure. The password-budget test no longer depends on running last.
- Each desktop/mobile case uses a test-scoped Playwright fixture, with a fresh disposable backend/database on an automatically selected loopback port. Test teardown terminates its process group. Startup readiness has a deadline.
- The production limits, security assertions, test timeouts and mutation behavior are retained. No failed operation is retried, no test is skipped and no limiter bypass is enabled.
- Failed-run artifacts were downloaded only to `/tmp` for investigation. They contain synthetic test data, not production customer content.

Local verification: 99 frontend cases, 28 API cases and 18 browser workflows. Remote verification is recorded below after the fix is pushed and GitHub finishes the new runs. Updating a dependency PR branch for verification does not merge that dependency into main.

Reference: [Playwright test-scoped fixtures](https://playwright.dev/docs/test-fixtures#overriding-fixtures).
