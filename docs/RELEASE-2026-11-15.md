# PasteBox release — 2026-11-15

Installed on https://pastebox.micutu.com/ at approximately 14:14 UTC. The live binary and every newly built static file were byte-compared with the tested artifacts. Old hashed assets remain available for existing tabs.

## Delivered

- Owner-only edit/delete and private reads; read passwords are separate capabilities.
- Explicit one-time reveal, atomic JSON/raw consumption and protected forks.
- Versioned scrypt, strict input validation, transactional tags, bounded throttles/database/connections, API no-store/noindex and consistent CSP.
- Search/language/tag filters and sorting; browser library/favorites with verified owner-key recovery.
- Responsive composer/viewer, templates, text-file import, JSON format, public-only opt-in drafts, safe downloads, code display controls and keyboard access.
- Lazy syntax grammars: initial JS roughly 125 KB / 47 KB gzip rather than 1,011 KB / 341 KB gzip.
- Homepage SEO/social card, app robots/sitemap, privacy-restricted existing analytics, pinned/read-only CI and dependency updates.
- Sanitized proxy identity, per-visitor ingress budgets, Cloudflare peer guard, public-only embed framing and query-free logs.

## Evidence

- 74 frontend test cases, 19 disposable API cases and 10 desktop/mobile browser flows passed.
- Native release build and a fresh Ubuntu 24.04 distribution build both passed the API suite. No production host packages were replaced.
- Public homepage, readiness, JSON API 404, static assets, robots, sitemap, social PNG and embed document passed read-only HTTPS smoke checks through Cloudflare. Security headers are checked for consistent values.
- A real browser loaded the public site without runtime errors; 375px and 320px layouts had no document overflow.
- Direct origin access from a non-Cloudflare peer returned 403; the normal Cloudflare route returned 200.
- Service active with no automatic restarts after release. Database integrity check passed; active record IDs from the pre-release snapshot were preserved.
- ShellCheck, shell/Python syntax, workflow YAML parsing, clean-install lockfile checks and nginx configuration validation passed.

## Material remaining work

Two low build-only npm advisories have no available upstream fix; the runtime dependency audit reports zero. Off-host encrypted backup scheduling, alerting, moderation/reporting, shared-host framework maintenance and an independent penetration/accessibility review remain planned. Plaintext storage is documented; end-to-end encryption, cross-device accounts, multi-file pastes and revision history are future increments.

Legacy ownership cannot be reconstructed from old records. Their data is retained, anonymous mutation fails closed, and old private records require verified operator recovery. Share links/read passwords must not be used as proof of ownership.

GitHub Actions is configured and its component commands were verified locally; remote execution awaits a repository push. No remote push was performed by this release. See the full [audit](SECURITY-AUDIT.md) and [roadmap](ROADMAP.md).
